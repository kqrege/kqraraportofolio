# Rules for the AI/code agent

Treat these as hard constraints unless the user explicitly changes them.

## Do

- build a real working site
- use `kq` lowercase everywhere
- make Roblox obvious immediately
- use the provided scroll-film skill as a reference for hero/motion craft
- use Lane A / pure-code motion only
- keep the page dark and mostly monochrome
- use real icon libraries / official brand assets
- make project content data-driven
- test desktop, tablet and mobile
- run the production build and fix all errors
- verify interactions after building

## Do not

- do not invent projects
- do not invent testimonials
- do not invent clients
- do not invent metrics
- do not invent prices
- do not display age, birthday, real name, personal photo, or Roblox avatar
- do not add GitHub at launch
- do not add a resume/CV download
- do not add a light theme
- do not add a contact form
- do not add public source code
- do not add live system demos
- do not autoplay project videos
- do not put project footage in the hero
- do not add website sound/ambience
- do not claim kq makes UI/GFX/VFX/SFX assets
- do not add a separate skills/technology section
- do not add fake availability status
- do not make pricing packages
- do not create individual pages for tiny systems
- do not hand-draw fake brand SVGs
- do not use AI-made decorative SVGs as filler
- do not turn the whole page into one long scroll movie
- do not use generic AI/SaaS visual clichés

## Content honesty

If real project/testimonial media has not been supplied yet, leave the data empty and hide that public section. Build the section/component so it is ready when the data arrives.

## Design review

Before calling the site finished, inspect it visually at desktop and mobile sizes.

Ask:

- does this look like a custom portfolio or a template?
- is `kq` memorable within the first screen?
- is it immediately clear that this is Roblox scripting work?
- can someone understand how to hire kq without hunting?
- does motion help the hierarchy or just prove GSAP is installed?
- did any generic dark SaaS pattern creep in?

Fix problems before handing it off.
