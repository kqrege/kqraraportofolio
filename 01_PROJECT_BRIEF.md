# Project brief

## Who this site is for

People looking to hire a Roblox scripter:

- Roblox game owners
- development studios
- lead developers / technical leads
- people commissioning scripting work

The site should make a visitor think: **kq is worth hiring, knows what he is doing, and can be trusted to do the job properly.**

## Positioning

kq is a Roblox **scripter / systems developer**.

Primary positioning: builds complete Roblox systems.

Secondary positioning: flexible enough to take almost any scripting task, including small one-off jobs.

Do not position kq as a UI designer, GFX artist, VFX artist, SFX creator, 3D artist, animator, or general creative studio.

kq can:

- script existing/provided UI
- add small UI interactions and micro-animations
- hook up provided sounds, VFX, icons, art, and other assets
- work from a detailed spec or help turn a rough idea into working system logic

## Hiring model

Keep it flexible. A client may hire kq for:

- one bug fix
- one small task
- one feature
- one complete system
- hourly work
- a day of work
- weekly work
- a fixed project
- ongoing development

Do not create package tiers or lock the site into one pricing model.
