# kq — Roblox Portfolio Build Brief

This folder is the source of truth for building the site.

The goal is a one-page portfolio for **kq**, a Roblox scripter available for hire. It should look like a real designer spent time on the art direction and motion, without turning into a generic AI-made dark SaaS page.

## What the builder should do

Build the real site, not a mockup and not another plan. If this ZIP is dropped into an existing repo, adapt to that repo. If there is no existing site, the preferred stack is in `09_TECH_BUILD_SPEC.md`.

Do not ask the user to repeat design decisions already written here. Ask only when something is truly blocking implementation, such as a missing real project video or a credential required to deploy.

Do not invent projects, testimonials, clients, metrics, prices, or experience. Empty content sections must be hidden until real data exists.
