# Section specs

## 1. Hero

Purpose: make `kq` memorable and explain the job in seconds.

Required content:

- giant lowercase `kq`
- `Roblox scripter`
- main line about building full systems / scripting work
- primary Discord contact
- secondary Telegram contact
- small location/timezone/experience metadata

No personal photo, avatar, project footage, GitHub, resume button, pricing table, or fake availability badge.

The hero should fill roughly one viewport on desktop.

## 2. Work

Only render when real finished projects exist.

Desktop layout:

- 2 columns when there are only a few projects
- 3 columns may be used when the library grows and cards still stay readable

Mobile: 1 column.

Project card anatomy:

1. poster / preview image
2. play affordance if a video exists
3. title
4. one-line description
5. technical details/tags
6. `My work`
7. `Provided assets` only when needed

Do not publish source code.

Do not create a project detail route for small systems.

If the portfolio later has one truly large project, the design may give it a larger feature card, but keep the one-page model unless there is a real reason to change it.

## 3. Services

Heading suggestion: `What you can hire me for`

Make it easy to scan.

The section should communicate both range and flexibility. It should not look like a services marketplace.

Include a small line explaining hiring formats:

`One task, a full system, hourly work, a day, a week, or ongoing development.`

No public price table.

## 4. How it works

Use a horizontal numbered line/sequence on desktop if it fits, stacked on mobile.

Keep the wording short.

## 5. Testimonials

Use 2–4 per view depending on width.

Each real testimonial can have:

- quote
- name/username
- role / studio / project if permitted

No star ratings unless the original source actually used them and there is a reason to reproduce them.

## 6. About

Prefer a text + metadata layout instead of a portrait.

Possible metadata items:

- Romania
- EET / EEST
- ~1.5 years scripting
- remote

Do not create a separate “tech stack” or “skills” section. Projects should prove technical ability.

## 7. FAQ

Accessible accordion.

Keep the visual treatment simple so it does not compete with Work.

## 8. Contact

This can be a larger closing section.

Suggested heading: `Got something that needs scripting?`

Actions:

- Discord `@kqrara` — copy handle
- Telegram — open link

Show payment methods nearby with restrained brand icons.

## 9. Footer

Small and quiet.

Suggested content:

`kq — Roblox scripter · Romania · EET/EEST`

Discord / Telegram links/actions.
